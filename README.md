## Numeros primos en la seguridad
Este es un proyecto diseñado para explicar de manera breve la importacia de los números primos en la seguridad de la informacion, ademas para verificar si un numero es primo garantizando un poco mas 
la seguridad de la informacion.

##  Descripción
La aplicación permite al usuario ingresar un número para determinar si es primo. A través de una interfaz moderna y responsiva, se educa al usuario sobre cómo los números primos actuan como la base
que sostienen algoritmos de cifrado como RSA.

## 🚀 Características
- **Algoritmo de Verificación:** Implementación de lógica de divisibilidad clásica, aplicando un for y verificando que el número introducido por teclado solo tenga dos divisores para determinar si el número es primo
  caso contrario no lo es.
- **Interfaz Moderna:** Diseño basado en una paleta de colores cian y temas oscuros (Tech/Security style).
- **Diseño Responsivo:** Adaptable a dispositivos móviles, tablets y computadoras de escritorio.
- **Explicaciones breves:** Explicaciones claras sobre la relación entre matemáticas discretas y seguridad, ademas de .

## 🛠️ Tecnologías Utilizadas
* **HTML5:** Estructura semántica.
* **CSS3:** Estylos personalizados, Flexbox y Media Queries.
* **JavaScript:** Lógica de programación (implementacion del algoritmo para verificar si un numero es primo) y manipulación basica del DOM.
